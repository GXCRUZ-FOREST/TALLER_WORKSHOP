# Taller: CNN pequeña para hojas de frijol

Proyecto personal para construir, entrenar e interpretar una red neuronal convolucional (CNN) desde pesos aleatorios. El caso proviene de la [sesión 2 del AI Workshop UNTRM](https://github.com/lobaton/AI-Workshop-UNTRM/tree/main/session2_inside_the_black_box/src).

La tarea consiste en clasificar fotografías de hojas de frijol en tres clases: mancha angular, roya del frijol y hoja sana. El conjunto `beans128` contiene 1.295 imágenes RGB de 128 × 128 píxeles, con particiones originales de entrenamiento, validación y prueba. Se usará la [copia publicada por el taller](https://github.com/lobaton/AI-Workshop-UNTRM/blob/main/session2_inside_the_black_box/src/data/README.md) como fuente de datos.

El trabajo se desarrollará según [PLAN_CNN.md](PLAN_CNN.md). Cada etapa terminada tendrá código, resultados y una explicación en este repositorio.
